mail-check

mail-check is a private, personal tool. Its developer uses it only on their own Gmail account. It is not offered to the public.

What it does

It reads new messages in the developer's Gmail account, creates short summaries in Japanese, sends those summaries to the developer's own messaging app, and labels advertising messages so they stay out of the inbox.

Privacy Policy

Last updated: November 9, 2026

Data accessed

With the account owner's permission, the tool uses the Gmail API to read messages and change message labels. It does not send email.

How data is used

Message content is used only to create summaries and sort messages for the account owner. To create summaries, message content is sent to a third-party language model API. Summaries are delivered through the owner's messaging service.

Sharing

Data is not sold, used for advertising, or shared with anyone except the service providers needed to create and deliver the summaries.

Storage

Access tokens and processing state are stored on the owner's computer. Access can be removed at any time from the Google Account security settings.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
